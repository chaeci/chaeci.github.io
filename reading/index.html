책 상세

설정 · 백업

👤 사용자 · PIN 관리

아이별 이름 · 출생연도 · 학년, 그리고 프로필 사진·이모지를 여기서 관리해요.

📅 출생연도를 입력하면 매년 3월 새 학기 기준으로 학년이 자동 갱신돼요. (예: 2026년 11월 초6 → 2027년 3월 중1)

📷 프로필 편집에서 얼굴 사진이나 이모지를 고를 수 있어요. 사진은 128×128 · JPEG로 압축해 함께 저장돼요.

PIN은 4자리 이상 숫자이며, 암호화된 해시(SHA-256)로만 저장돼요. PIN을 바꾸면 다른 기기에도 동기화할 때 함께 반영돼요.

PIN을 잊으면 이 기기의 브라우저 데이터를 지워 다시 만들어야 하고, 기록은 백업 파일이나 GitHub에서 다시 불러와야 해요. 잊지 않게 적어 두세요.

GitHub 동기화

아직 연결되지 않았어요.

아직 동기화한 적이 없어요.

버튼을 누르면 공유 창(퀵쉐어·카카오톡 등)이 떠서 바로 보낼 수 있어요. 공유 창이 없는 브라우저에서는 링크가 클립보드에 복사돼요. 새 폰·태블릿에서 이 링크를 열면 GitHub 설정과 기록·PIN이 자동으로 연결돼요. 링크에는 저장소 주소와 토큰이 들어 있어요. 가족 기기(카톡 등)에만 보내고, 연결 후 메시지는 지워두면 더 안전해요.

아이들 태블릿과 이 기기가 같은 reading-db.json을 함께 씁니다. 토큰은 이 기기에만 저장되고 DB 파일에는 들어가지 않아요. 연결된 기기는 앱을 열 때마다 최신 기록을 자동으로 받아와요.

🔍 도서 검색 설정

아직 검색 키가 없어요.

무료예요. 카카오 developers → 내 애플리케이션 → 앱 만들기 → REST API 키를 복사해 붙여 넣어 주세요. 넣으면 국내 책을 바로 찾아요.

키 없이 쓰면 구글 공용 한도(하루 쿼터)가 차서 검색이 막힐 수 있어요.

키는 아이들 기록과 함께 비공개 GitHub DB(reading-db.json)에 저장돼 폰·태블릿에 함께 적용돼요. JSON 백업 파일에도 들어가니 백업 파일을 남에게 보내지 마세요.

기록 백업

브라우저 기록을 지우거나 휴대폰을 바꾸면 기록이 사라져요. 가끔 파일로 내려받아 두세요.

샘플 · 초기화

처음 넣어 둔 샘플 책이에요. 지우고 우리 아이 책만 남겨도 돼요.

채씨네 작은도서관 · 기록은 이 기기 브라우저에만 저장돼요.

GitHub 동기화

GitHub 저장소의 reading-db.json 파일 하나로 아이들 태블릿과 이 기기의 기록을 맞춰요.

Fine-grained 토큰은 이 저장소의 Contents: Read and write 권한만 주면 돼요. 토큰은 이 기기 브라우저에만 저장되고 DB 파일·백업에는 절대 들어가지 않아요.

저장하지 않고 닫아도 이 기기의 기록은 그대로예요.

PIN 설정

4자리 이상 숫자로 정해 주세요.

프로필 편집

아이 얼굴 사진이나 이모지로 프로필을 꾸며요. 사진은 이 기기와 동기화 저장소에 함께 저장돼요.

「갤러리」는 앨범·파일에서, 「바로 촬영」은 카메라를 여는 버튼이에요. 정사각형으로 가운데를 잘라 128×128 · JPEG로 압축해 저장해요(10KB 안팎).
